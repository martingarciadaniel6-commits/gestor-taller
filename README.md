# Gestor de Taller — Versiones

Instaladores oficiales de **Gestor de Taller**.

- **Windows**: descarga el `.exe` de la última versión en
  [Releases](../../releases/latest). Los equipos ya instalados se
  **actualizan solos** al abrir la aplicación.
- **macOS**: descarga el `.dmg` e instala encima (la activación y los datos
  se conservan).

El software se activa con clave de licencia. Sin una clave válida no da
acceso a ningún dato.
